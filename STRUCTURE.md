## 📐 Section Dimensions

| Section | Height | Background |
|---------|--------|------------|
| Navbar | 80px | White/Blur |
| Hero | 70vh | Gradient + Grid |
| Stats | Auto | White |
| Packages | Auto | Gradient |
| Carousels | Auto | White |
| Testimonials | Auto | Dark (Slate-900) |
| Duration | Auto | White |
| Partners | Auto | Gradient (Pink/Orange) |
| Footer | Auto | Dark (Slate-900) |

## 🎨 Color Scheme

### Primary Colors:
- **Brand**: Red-600 (#DC2626)
- **Accent**: Orange-500 (#F97316)

### Backgrounds:
- **Light**: Slate-50 (#F8FAFC)
- **Dark**: Slate-900 (#0F172A)
- **Gradient**: Red to Orange

### Text:
- **Primary**: Slate-900 (Light) / White (Dark)
- **Secondary**: Slate-600 (Light) / Slate-300 (Dark)

## 📱 Responsive Breakpoints

```
Mobile     Tablet      Desktop     Large
< 640px    768px       1024px      1280px+
─────┬────────┬──────────┬──────────┬─────
  📱 │    📱  │    💻    │    🖥️    │ 🖥️🖥️
```

### Layout Changes:
- **Mobile**: Single column, stacked
- **Tablet**: 2 columns
- **Desktop**: 3-4 columns
- **Large**: Full width, max container

## ⚡ Animation Types

| Component | Animation Type | Trigger |
|-----------|---------------|---------|
| Hero | Fade In + Grid Sequence | On Mount |
| Stats | Counter + Fade | On Scroll |
| Packages | Stagger + Lift | On Scroll |
| Carousel | Slide + Zoom | On Hover |
| Testimonials | Fade + Scale | On Scroll |
| Partners | Scale | On Hover |

## 🔗 User Flow

```
Landing → Hero (CTA)
  ↓
Explore Stats
  ↓
Browse Packages → Book
  ↓
Discover Destinations
  ↓
Read Testimonials
  ↓
View Duration Options
  ↓
Check Partners/Trust
  ↓
Footer Contact → Inquire
```

## 📊 Content Hierarchy

```
Level 1: Hero Message (Primary CTA)
  ├── Level 2: Stats (Trust Building)
  │   └── Level 3: Packages (Primary Products)
  │       ├── Level 4: Destinations (Browse)
  │       ├── Level 4: Testimonials (Social Proof)
  │       └── Level 4: Partners (Credibility)
  └── Level 5: Footer (Contact/Info)
```

## 🎯 Call-to-Actions

1. **Primary**: "Start Planning" (Hero)
2. **Secondary**: "Book Now" (Packages)
3. **Tertiary**: "View All" (Various sections)
4. **Contact**: "Get Quote" (Navbar)
